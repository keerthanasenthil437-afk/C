\# Tic Tac Toe in C 🎮



A simple console-based Tic Tac Toe game written in C.



\## 📌 Features



\* Two-player mode

\* 3x3 game board

\* Input validation

\* Win and draw detection



\## 🛠️ Technologies Used



\* C Programming

\* Console (Terminal)



\## ▶️ How to Run



\### Compile:



```

gcc tictactoe.c -o game

```



\### Run:



```

./game

```



\*(On Windows use: `game.exe`)\*
