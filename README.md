# 💻 C Console Games

This repository contains simple console-based games developed using C programming.

---

## 🎮 Projects Included

### 🐍 Snake Game
- Console-based snake game
- Uses keyboard input
- Score tracking system

### ❌ Tic Tac Toe
- Two player game
- Uses 2D arrays
- Win/draw logic implementation

---

## 🛠️ Technologies Used
- C Programming
- GCC Compiler
- Basic Data Structures (Arrays)

---

## 🎯 Concepts Used
- Arrays
- Functions
- Loops
- Conditional Statements
- Game Logic Design

---

## 🚀 How to Run

### Compile:
gcc snake.c -o snake  
gcc tictactoe.c -o tictactoe  

### Run:
./snake  
./tictactoe
